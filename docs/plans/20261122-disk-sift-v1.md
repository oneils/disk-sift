# DiskSift v1: app uninstaller and junk cleaner for macOS

## Overview
- DiskSift is a personal macOS GUI app in the spirit of AppCleaner / CleanMyMac:
  1. **Uninstall**: drag a `.app` from `/Applications` into the window; DiskSift finds its leftovers (preferences, caches, containers, launch items, pkg receipts), shows them with a confidence level and moves the app plus the checked leftovers to the Trash.
  2. **Junk cleanup**: scan user caches/logs and developer junk (Xcode, Homebrew, npm, pip, cargo, go), show sizes per category and permanently delete what is checked.
- No background agent, no App Store, no sandbox. Phase 1 is ad-hoc signed for personal use; Developer ID + notarization may come later and must not require architectural changes.
- Greenfield project in `~/projects/disk-sift` (empty, not yet a git repo).

## Context (from discovery)
- Toolchain on this machine: Command Line Tools only (no Xcode), Swift 6.4, macOS 27, arm64. Verified: `swift test` with Swift Testing works under CLT; `swift format` ships with the toolchain. No `xcodegen`, no `swiftlint`.
- **Decision: SwiftPM only, no Xcode project.** The app is an executable target; `scripts/make-app.sh` assembles `DiskSift.app` (Info.plist, resources, ad-hoc codesign). No SwiftUI previews or Instruments; acceptable for v1.
- Release/CI conventions mirrored from `~/projects/booknook` and `~/projects/saldo`: `ci.yml` on push/PR/workflow_dispatch with `permissions: contents: read`; `release.yml` on `v*` tags with `permissions: contents: write`, `actions/checkout@v7` + `fetch-depth: 0`; changelog excludes `^docs:`, `^test:`, `^chore:`, `Merge pull request`, `Merge branch`; `checksums.txt` attached. goreleaser can't build macOS app bundles, so the release job is a plain shell pipeline.
- Repo may become public: no secrets, home hostnames or personal identifiers in it.

## Solution Overview
- `Package.swift` (tools 6.0, `.macOS(.v14)`) with three targets:
  - `SiftCore` (library, no SwiftUI/AppKit UI): all scanning, matching, sizing, removal logic
  - `DiskSift` (executable, SwiftUI + AppKit): windows, `@Observable` view models, drag & drop, running-app handling
  - `SiftCoreTests`, `DiskSiftTests` (test targets)
- Everything that touches paths gets an injected `Environment`, so the whole core runs against temp-dir fixtures.
- Extension points are protocols: `LeftoverSource` (a known-paths DB can be added later as one more source), `JunkCategory`.
- Safety lives in `Remover`, not the UI: allowed-roots whitelist, no symlink following, root-owned items never removed.
- Localization: English source strings as keys, `Resources/{en,ru}.lproj/Localizable.strings` copied into `Contents/Resources` by `make-app.sh` and read through `Bundle.main` (SwiftPM resource bundles for executables end up in the `.app` root and break code signing; `.xcstrings` needs Xcode to compile). `swift run` without a bundle falls back to the English keys.

### Core types
```swift
struct Environment: Sendable { home, library, systemLibrary, applications, tmp: URL; static let live }
protocol CommandRunner: Sendable { func run(_ exe: String, _ args: [String]) async throws -> CommandResult }  // stdout, stderr, status
enum Confidence: Int, Comparable { low, medium, high }
enum FindingSource { libraryPath, launchItem, pkgReceipt, junk(categoryID) }
struct Finding: Identifiable, Sendable { url, size: Int64?, confidence, sources: Set<FindingSource>, requiresRoot, inaccessible: Bool }
enum RemovalPolicy { trash, delete }
struct AppInfo { url, bundleID, name, teamID: String?, nestedBundleIDs: [String], isAppleSigned: Bool }
protocol LeftoverSource: Sendable { func findings(for app: AppInfo, env: Environment) async throws -> [Finding] }
protocol JunkCategory: Sendable { id, title, policy (.delete); func scan(env:) async throws -> [Finding]; func checkedByDefault(_:) -> Bool }
struct RemovalReport { removed: [(URL, Int64)], skipped: [(URL, SkipReason)] }
```

### Matching rules (LibraryPathsSource)
- Directories: `~/Library/{Application Support, Caches, Preferences, Preferences/ByHost, Containers, Group Containers, Saved Application State, Logs, HTTPStorages, WebKit, Cookies, LaunchAgents, Application Scripts, Autosave Information}` and `/Library/{Application Support, Caches, Preferences, Logs, LaunchAgents, LaunchDaemons, PrivilegedHelperTools}` (~25 dirs).
- Only direct children are checked; the name is stripped of known extensions (`.plist`, `.savedState`, `.binarycookies`) before matching.
- **high**: name == bundle ID / nested bundle ID, or starts with `<bundleID>.`; **medium**: `Group Containers/<TEAMID>.*`; **low**: name equals the app name, case-insensitive, app name ≥ 4 chars.
- `requiresRoot`: item or its parent not writable by the current user (`access(W_OK)`).

### Merge (FindingMerger)
- dedupe by standardized path; union sources; max confidence; drop children whose ancestor is also a finding.

### DirectorySizer
- `fts_open` with `FTS_PHYSICAL | FTS_NOCHDIR`, sums allocated size (`st_blocks * 512`, matches `du`), counts hard links once by `(dev, ino)`.
- top-level children sized concurrently in a `TaskGroup` (bounded to CPU count); `Task.checkCancellation()` every 1000 entries.
- `EACCES` on entries → result marked `inaccessible`, partial size kept.

### Removal
- Allowed roots: `env.library`, `env.systemLibrary`, `env.applications`, `~/.npm`, `~/.cargo`, `~/go/pkg/mod`, `~/Library/Developer`. A path is allowed only if it is strictly inside a root (never a root itself).
- `lstat` is used; a symlink is removed as a link.
- Go module cache is read-only by design: `chmod -R u+w` the target before `removeItem` (same as `go clean -modcache`).
- Per-item errors (`EACCES`, `EPERM`, `EBUSY`, `ENOENT`) → `skipped` with reason; `requiresRoot` → skipped with `.needsAdmin`, never attempted.

### Junk categories
- `UserCachesCategory`: children of `~/Library/Caches` and `~/Library/Logs`, excluding paths owned by `DevJunkCategory`; `com.apple.*` unchecked by default.
- `DevJunkCategory`: `~/Library/Developer/Xcode/DerivedData`, `~/Library/Developer/Xcode/Archives` (unchecked by default: contains dSYMs), `~/Library/Developer/Xcode/iOS DeviceSupport`, `~/Library/Developer/CoreSimulator/Caches`, `~/Library/Caches/Homebrew`, `~/.npm/_cacache`, `~/Library/Caches/pip`, `~/.cargo/registry/cache`, `~/Library/Caches/go-build`, `~/go/pkg/mod`. Missing paths are skipped silently.
- Deleting unavailable simulators needs `xcrun simctl` (Xcode) → out of scope.

### Uninstall flow
drop `.app` → `AppValidator` (is `.app`, has `CFBundleIdentifier`, not under `/System`, not Apple-signed, not DiskSift itself) → `AppInfo` → if running (`NSRunningApplication`) ask to quit: `terminate()`, wait up to 5 s, offer `forceTerminate()` → `LeftoverScanner` (sources in parallel, merge, size) → list grouped by parent dir; high/medium checked, low unchecked, root items greyed → Trash app + checked items → report.

### Junk flow
Scan → categories in parallel, per-category progress and totals → user unchecks → confirmation with total size → permanent delete → report with skipped items.
